# Apollo NFC-1

NFC tag reader and writer for Home Assistant, built on ESPHome.

**Key Features of the NFC-1:**

- NXP PN7160: scan tags into Home Assistant, write/clean/format tags, and card emulation
- RGB LED and buzzer feedback
- ESP32-C6 with 8MB flash, Wi-Fi, Bluetooth proxy, and Improv setup
